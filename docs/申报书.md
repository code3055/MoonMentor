# MoonMentor 申报事实材料（供本人定稿）

**1. 项目名称**：MoonMentor 学习助手

**2. 项目简介**：MoonMentor 面向 MoonBit 初学者，记录练习结果，估计知识点掌握情况，并安排下一段练习。用户可以通过命令行或本地网页查看掌握度、错误提醒和学习计划，学习记录不上传服务器。

**3. 项目方向、通用性说明**：项目属于 AI 应用和开发者工具方向。它使用掌握度更新、前置知识关系和时间预算规划来安排学习，不依赖特定模型服务。课程文件和练习题可以替换，因此也可用于其他编程语言、考试科目或企业培训。

**4. 预期使用场景**：

1. 初学者练习 MoonBit 后导入答题记录，得到下一步练习建议。
2. 培训教师按班级导出的练习记录，查看常见错误并安排复习内容。
3. 团队维护内部技术课程，用知识点前置关系和时间预算生成短时学习计划。

**5. 拟实现的核心功能**：课程和练习题解析；答题正确率、提示使用和耗时记录；知识点掌握度更新；多知识点练习关联；前置知识检查；错误标签汇总；带时间预算的多步练习计划；文本、JSON 和网页报告；MoonBit JS bridge。

**6. 项目性质**：原创应用项目。没有移植其他项目的源代码；BKT 等算法属于公开方法，代码和应用流程由本项目自行实现。
