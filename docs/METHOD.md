## 本地验收

执行 moon fmt --check、moon check、moon build、moon test；构建浏览器 bridge 后执行 node --test web/app.test.mjs。后者调用真实 MoonBit 输出检查页面渲染和输入错误。

moonc 已验证版本为 0.10.14。网页启动还需要 Python；集成测试需要 Node.js 22。CI 安装官方最新 MoonBit，远端结果以 Actions 为准。
